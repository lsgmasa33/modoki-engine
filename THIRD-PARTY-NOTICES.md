## Vendored data (NOT an npm dependency)

### `engine/packages/modoki/src/runtime/rendering/gpuBenchmarks.ts` — GPU throughput table

A table mapping a normalized WebGL renderer string to a single throughput figure, used to pick one
of three quality tiers on Android. Generated by `engine/scripts/gen-gpu-benchmarks.mjs`.

- **Source**: GFXBench 5.0 toplist results, published by Kishonti Ltd at
  https://github.com/Kishonti-Opensource/GFXBench_and_CompuBench_results
- **Copyright**: © 2005–2025 Kishonti Ltd
- **Licence**: **CC BY 4.0** — https://creativecommons.org/licenses/by/4.0/
  (the repository is dual-licensed: BSD 3-Clause for code, CC BY 4.0 for non-code assets)

**Changes were made** — stated here because CC BY 4.0 requires it. From the published CSV we:
select rows for a single test (`1080p Manhattan Offscreen`) on Android GPUs only; reduce the
per-device medians to one median per GPU; retain the submission count alongside each figure; strip
vendor prefixes, ANGLE wrappers and core-count descriptors; and renormalize the keys. The retained
figure is consumed only by `tierForBenchmarkFps` to choose `low`/`mid`/`high` — it is never
displayed, exported as a benchmark result, or presented as a GFXBench score.

⚠️ Until 2026-08-13 this also said *"drop GPUs with fewer than three submissions"*, and that
sentence is now retired rather than edited quietly: the generator keeps every GPU with at least one
submission (84 rows → 132), and thin rows are instead rounded down to the lower band when they sit
close to a boundary. The derivation is in `gen-gpu-benchmarks.mjs`. Nothing about the licence
position changes — the same figures from the same test, aggregated less aggressively.

**Why this source.** GFXBench and CompuBench were retired in December 2025 after 21 years, and
Kishonti open-sourced both along with a snapshot of the results database. Taking the figures from
the party that measured them, under an explicit grant, replaced an earlier table derived from a
third-party republication whose own upstream rights were an open question. A first-party grant is
strictly stronger than a good-faith reading of someone else's licence.

✅ **Use of this data was confirmed directly by Kishonti Ltd, by email, on 2026-08-12** — "You are
free to use the data and thanks for the reference." The correspondence is held by the project owner.

⭐ **The attribution below is the exact wording that was put to the rights holder and approved.**
Reproduce it verbatim; do not paraphrase, retitle or "tidy" it. It is also emitted into the header
of the generated table so it travels with the data, and a guard test asserts both copies still match
it word for word.

```
GPU performance data derived from GFXBench and CompuBench toplist results,
(c) 2005-2025 Kishonti Ltd, licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). Values were aggregated and
modified from the published results.
```

That confirmation was sought because the asset half of the licence enumerates "textures, models,
animations, sound effects, and music" and does not name results CSVs. The published licence already
partitions the project into exactly two halves — code and non-code assets — and the repository
contains nothing but results CSVs, a LICENSE and a README, so whichever half the data falls in both
are permissive and compatible with redistribution under Apache-2.0. The reply removes the need to
rely on that reading. Their public contact for licensing questions is `opensource@kishonti.net`,
offered in their own LICENSE.

**Attribution is kept regardless of the grant**, both because CC BY 4.0 is the licence the data was
published under and because the reference was expressly welcomed.

⚠️ GitHub reports that repository as `NOASSERTION` — its detector cannot classify a dual licence —
so no automated scanner will resolve this on our behalf. This notice is the only one there is.

## License-compatibility notes

- **GSAP** (non-permissive "Standard 'no charge' license") was previously a declared dependency but
  is **not used by the engine** — no source imported it. It has been removed from the engine's
  dependencies, so it does not ship in this repository. A game project that wants GSAP may add it
  as its own (game-scoped) dependency and comply with GSAP's license there.

Where a dependency requires reproduction of its license text and/or copyright notice, that text is
included in the generated `oss/licenses/` output shipped with releases.
